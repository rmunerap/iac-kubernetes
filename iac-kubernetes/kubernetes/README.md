# Kubernetes IaC – Parte 1

Este repositorio contiene la infraestructura como código (IaC) para desplegar
recursos básicos en un clúster de Kubernetes utilizando manifiestos YAML.

## Contenido
- Deployment Kubernetes
- Service Kubernetes
- Pipeline en Azure DevOps para despliegue automático

## Requisitos
- Kubernetes (Minikube)
- kubectl
